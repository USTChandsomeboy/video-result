# Video Seed Bench 对比页

打开 `index.html` 查看原视频与 Remotion 首次复刻的同步对照。
本目录由 `publish_viewer.py` 生成，只包含网页和网页实际使用的媒体文件。

SVG 眨眼动画教程与 Rome Epic 两组复刻案例见 [`replicas.html`](replicas.html)。该页直接播放 GitHub Release 中按 SHA-256 登记的完整成片，显示评分、检查覆盖率和主要差异。发布说明见 [`remaining-replicas-README.md`](remaining-replicas-README.md)。

- [X-Reels：8 条完整视频复刻与最新评分](https://ustchandsomeboy.github.io/video-result/experiments/x-reels-standard/compare.html)：Kinetic、LinkPulse、Showreel、Reel26、FullStop、Horizon、TeamLaunch、SketchDay。页面提供同步对比、总分、分项、源码与检查记录下载。

- [Paper Girl：写信给太阳](https://ustchandsomeboy.github.io/video-result/experiments/paper-girl-standard/compare.html)：28 秒剪纸动画，37.5 分，47 个对象、1,193 项检查。
