# 七雄并立：原作与复刻的代码差异

对比的是这次固定的独立复刻，`Replica.tsx` 的 SHA-256 为 `e96ad81d1f7f7f7cf2672441a2eab2fe6882615e8f561e3c6b84552dafa40bdf`。原作素材已经提供给复刻 agent；以下关注代码如何控制这些素材和画面元素。

## 1. 战事标记缺少两种缩放

原作 `Map.tsx` 的 `Markers` 同时使用 `pop` 和 `1 / s`：标记出现时从 1.8 倍缩回正常大小；镜头缩放时，标记通过反向缩放保持屏幕尺寸。

复刻 `Replica.tsx:154` 只有位置和透明度，没有对应的缩放。因此标记能出现、地名也正确，但入场动作和镜头联动不完整。

```tsx
// 原作
const pop = tw(f, a, a + 10, 1.8, 1);
const k = 1 / s;
transform={`translate(${x} ${y}) scale(${k * pop})`}

// 复刻
transform={`translate(${b.x} ${b.y})`}
opacity={fade(t, b.start, b.end, .32)}
```

## 2. 国名会移动，但字号没有跟随疆域变化

原作根据每个阶段的疆域大小计算 `labelFont(s)`，过渡时分别插值国名的位置和字号。

复刻 `Replica.tsx:32` 为每个国家设置固定 `size`，`countryPosition` 只改变位置，绘制时仍使用 `fontSize={c.size}`。例如“秦”一直使用同一个基础字号。镜头本身带来的缩放仍然存在，但没有还原原作独立的字号变化。

## 3. 字幕的出现、消失和位置过程不同

原作 `data.ts` 为 19 段字幕分别记录帧区间，`Overlay.tsx` 在首尾各 5 帧做透明度变化。

复刻重新估算了各段秒数，并统一使用 0.23 秒渐变，还额外增加了 10 像素的上移。例如第二段字幕原作在第 179–223 帧，即约 5.97–7.43 秒；复刻设置为 5.8–8.0 秒。文字正确，并不代表进出时间和入场动作相同。

## 4. 结尾标题提前切换

原作旧标题在 75.00–75.73 秒淡出，新标题在 75.20–75.97 秒淡入，两个过程分别控制。

复刻 `Replica.tsx:128` 从 74.10 秒就开始切换，并在 75.35 秒结束，旧标题直接采用 `1 - next`。这改变了切换的开始时间、持续时间，以及两个标题重叠的过程。

## 5. 年份变化采用了另一条时间曲线

原作 `yearAt` 使用年份关键帧和二次缓动；复刻用自己观察得到的 `yearKeys` 做分段线性插值。两个实现都能显示年份递减，但中间年份及停留时长不完全一致。

年份字体也不同：原作使用 `Kaiti SC`，复刻 `Replica.tsx:122` 改成了 `Times New Roman,serif`。本次会检查字体属性，但不比较浏览器实际字形像素。

## 6. 疆域扩张被识别出来，但推进方式仍有差别

复刻正确使用了 `time_*.png` 控制疆域逐步出现，并没有简单地把两张图片做整幅淡入淡出。这是已经复刻到的关键机制。

原作使用颜色矩阵形成 alpha 遮罩，并用 `0.35 * sin(πp)` 控制推进前沿亮度；复刻使用亮度遮罩、分通道阈值和固定透明度的带状矩形。评分器会先将受支持的两种表示换算成共同的通道观测，再比较实际作用的对象、变化曲线和时间。代码写法不同本身不扣分。

## 如何理解本次分数

六维分别是元素存在、元素属性、相对关系、动效绑定、运动参数和进出时序。总体布局与主要对象比较完整，不能掩盖局部动作、字号变化和时序的差异；因此这些项目分别评分。

评分描述的是已声明的源码检查。精确字形、纸张与笔触滤镜的最终像素，以及音频波形，没有计入这次源码分数。
