## 需要结合画面判断的部分

38秒原片的金色疆域轮廓清楚可见，复刻里未清晰呈现。复刻代码确实加载了三个距离场纹理并实现 `boundary()`，因此不能仅凭函数存在就说已正确复现；还需要核对实际材质绑定、最终输出、区域形状和随时间的变化。该画面现象的具体运行原因尚未单独定位。

光照、海面、雾、泛光和完整字体像素也存在差异。源码评分只覆盖已声明且通过校准的测量，不能解释为全画面像素相似度。
