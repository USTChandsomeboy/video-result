相似的画面，哪些过程没有还原？

以下来自原作与本次冻结复刻源码的直接对照。视频用于确认这些代码差异的实际表现；这里列出的说明不额外改动自动分数。

1. 羽毛下落：换了运动规律

开场与空气实验 · intro.feather / air.feather
原作：速度逐渐趋于稳定，摆动随时间建立。
const d = vt * t - vt * 10 * (1 - Math.exp(-t / 10));
const k = Math.min(1, t / 20);
dx = Math.sin(t / 13) * 46 * k;
rot = Math.sin(t / 13 + 1.3) * 30 * k;
复刻：纵向匀速插值，横向和旋转改成另一组正弦。
falling = inp(t, 12, 17);
fy = 200 + falling * 330;
fx = 1400 + Math.sin((t-12)*5) * 55 * ...;
rot = Math.sin((t-12)*5.4) * 28;

都能看出“羽毛飘落”，但加速过程、摆动频率、幅度和落地时间不同。这体现了模型抓住动作大意，却没有反推出运动曲线。

左侧公式的 t 是局部帧数，右侧 t 是视频秒数；评分时按 30 fps 换算到相同的视频时刻比较。

2. 绑球实验：移动起点和绳子关系不同

约 30–32 秒 · thought.tied-heavy / thought.tied-light / thought.rope
原作：重球和轻球从各自位置移动到同一竖线上，绳子的端点跟随两球。
cL = {x: mix(1010, 1400, tie), y: mix(300, 214, tie)};
cH = {x: mix(760, 1400, tie), y: mix(300, 330, tie)};
path = `M${cL.x} ${cL.y+30} Q ... ${cH.x} ${cH.y-58}`;
复刻：重球从更靠右的位置出现；绳子下端固定在最终位置。
heavyX = mix(1240, 1400, tied);
heavyY = 330;
path = `M${tx} ${ty+30} Q ... 1400 274`;

最终布局接近，但移动中的重球路径、绳子端点和连接过程不同。检查相对关系需要覆盖整个移动过程，不能只检查最后一帧。

3. 约去质量：只淡出，没有收拢空位

约 54–56 秒 · formula.mass-left / formula.mass-right
原作：字母淡出、向上移动，宽度同时缩到零，后面的字符自然收拢。
width: mix(size * 0.86, 0, gone),
opacity: 1 - gone,
transform: `translateY(${-gone * 40}px)`
复刻：质量字母固定宽度，仅淡出；后续字符另行绝对定位。
width: 73,
height: 100,
// m glyph
opacity: fade
// 另一个 div 显示 a = g

“m 消失了”被还原，但没有还原删除字母带来的排版变化。视频里等式在过渡期间更松散，字符之间的衔接也不同。

对应自动检查（等式左侧 m）：淡出曲线 55.13 分，删除线绘制过程 0 分，宽度收拢 0 分。

4. 抽走空气：吸走轨迹换成依次消失

约 68–72 秒 · vacuum.molecules
原作：70 个分子在管内反弹，再沿各自时间逐渐移到顶部出口。
const k = ramp(f, p.leave, p.leave + 26, INOUT);
cx = mix(ax, (TUBE.l + TUBE.r) / 2, k);
cy = mix(ay, TUBE.t - 10, k);
opacity = 0.7 * (1 - k);
复刻：90 个分子持续循环运动，按编号依次降低透明度。
const remain = clamp((1-pump)*90 - i + 1);
px = (...) % 330;
py = (...) % 435;
opacity = remain * .8;

两者都从“很多分子”变成“没有分子”，但只有原作表现了空气被吸向出口的过程。这是终态相同、运动机制不同的典型例子。自动检查中，“分子被抽走的轨迹”得 0 分。

如何看待这次分数

分数检查 25 个公开对象的存在、属性、相对关系、绑定、运动参数和进出时序。它不等同于整片画质分：角色表情、所有装饰、字体像素效果、音频听感没有全部计入。

“动效绑定 100”表示该项要求的属性确实有时间驱动；具体是否按原作的幅度、速度和时间变化，要看运动参数与进出时序。例如开场铁球的下落绑定是 100，但下落曲线是 0。

305 / 305 表示已登记的检查全部可测。本版绳子检查覆盖终态形状、相对位置、透明度和进出时序；还没有直接评分“移动时绳子两端始终连接两球”这一约束。上面第 2 项属于源码复核发现的问题，不能把绳子绑定项的 100 理解成整个连接过程正确。

本版颜色检查按颜色值和渐变色停点精确比较；很小的色差也可能扣掉该项。应结合六维分数、逐项源码证据和视频来看，不能把总分当作人的审美判断。
