# R20：Animated growth chart data infographic

## 选片理由

输入 seed 是 `topology_reveal`、`multi_series_continuity` 和 `annotation_binding`，类别是数据叙事（可视化）。片段是年度报告界面，多条折线、图例、年份、坐标轴和底部摘要数字逐步出现，适合检验数据路径和说明文字是否共享状态。

来源：[Animated growth chart data infographic](https://mixkit.co/free-stock-video/animated-growth-chart-data-infographic-5424/)。本地片段为前 15 秒，24fps、1280×720、360 帧。

## 当前复刻暴露的问题

- 图表框架可以复刻，但标题、图例、坐标轴和曲线的初始时间略有偏差。
- 多条曲线都能画出，但走势和局部波动被规则化，独立序列的变化没有完全保持。
- 图例颜色保留了，但具体图例和曲线路径之间的绑定较弱。
- 底部摘要数字能出现，但和最终曲线状态没有完全同时完成。

这条片段适合验证 `chart_initial_state`、`multi_series_continuity`、`annotation_binding` 和 `summary_chart_binding`。
