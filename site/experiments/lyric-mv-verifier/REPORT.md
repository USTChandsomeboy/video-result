# 歌词 MV：素材合成 GT 与 SVG 重绘的评分

本次将第一版素材合成成片作为 GT，将最新 SVG 独立重绘成片作为复刻。评分脚本读取两份源码和实际素材，由已标注的绘制节点建立对象对应。展示页左侧使用去除抖音标识、账号文字、开场导演和监制署名，以及末尾推广卡片的版本；原始评分依据和 50.3 分结果保留。

**本次评分：50.3 / 100。** 评分包状态为 `valid`，声明的 658 项检查全部有数值，覆盖 110 个图层对象、25 段场景、743 个采样帧。原作和复刻已有视频的 7 个关键帧分别与源码快照、几何测量核对，通过主体区域检查。

## 这个分数的范围

本次比较图层对象的可见存在、几何、颜色分布、相对位置、变化幅度和过程，以及可见时间。GT 人物的关节和表情已烘焙进图片，无法从这份 GT 代码恢复原始关节函数、弹簧参数或素材制作过程。因此该分数是本案例的图层与可见动效分数。

字幕覆盖可见字形范围、位置和出现时间，歌词逐字内容尚未核验；不能把字幕分数解释为文字内容已全部正确。群体依照 GT 的已有合成图层比较，五位伙伴另检查重绘实际绘制成员数量，但未逐一追踪 GT 每位人物的关节。

平台角标、作者账号文字、最后 66 帧的推广收尾和音频不计分。安全 SVG 几何测量以 320×180 网格计算，浏览器滤镜、细小笔触和抗锯齿存在近似差异。该验证程序已在公布检查范围内完成校准，尚不能用于任意视频。
