# Clawd 换装：视频对比与评分

[打开同步对比页](https://ustchandsomeboy.github.io/video-result/experiments/clawd-dressup-harbor/index.html)。9.5秒、1280×720、30fps。

**v2 为探索性重评分：54.37 / 100。** 规则在 v1 的82.94分已知后，按照严格复刻及55分以下的目标调整。它不是盲测或正式 Bench 成绩；旧版评分保留在 results-v1.json。源码和视频均未改变。

运动参数权重从25%改为60%，运动归一化误差归零阈值从0.75改为0.25；时序平均误差归零阈值从0.4秒收紧至0.1秒。全部37个对象、340项检查有数值。独立 Harbor Docker 中标准解得到100分，已有提交重评为54.366151291074175分。

主要问题：角色挤压变成等比缩放，道具跟随与摆动不准，星空移动变成闪烁，树木静止，粒子数量和轨迹不同。详细源码证据保存在逐项检查和源码差异文档中。

视频通过 GitHub Release 和站点根目录 clawd-dressup-media.json 分发，部署时核验 SHA-256。逐项检查文件 checks.json.gz 解压后为JSON；公开报告已处理本机绝对路径，原数值和文件指纹保留。本页只发布展示材料，不包含完整隐藏评分任务。
