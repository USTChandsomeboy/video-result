# Clawd 换装：源码差异复核

基于独立 agent 冻结提交与原作源码核对。下面的结论帮助解释差异，自动分数由封存 verifier 另行计算。

## 1. 角色弹出：挤压回弹变成了等比缩放

原作在3秒附近同时改变横向和纵向缩放，并让身体下沉；复刻只给整个身体一条等比缩放曲线和小幅上下摆动。第90帧能看到原作更宽、更扁，复刻偏高。

- 对象：`clawd.bare`, `clawd.bare-eyes`
- 查看时间：3.00 秒
- 原作：src/dressup.tsx:30：scaleX = pop × (1 + 0.11 × exp(...))；scaleY = pop × (1 − 0.12 × exp(...))；位置另加28px下沉。
- 复刻：src/Replica.tsx:62–65：scale = interpolate([82.5,84.5,88,91], [.05,1.12,.97,1])；使用scale(scale)，位置为371 + 3sin(...)。

## 2. 雨伞和头盔：相似造型，运动方式不同

原作雨伞跟随角色上下运动并持续小幅转动；复刻雨伞的角度固定为−29°。原作头盔出现后持续左右、上下和旋转；复刻加入从画面外飞入的过程，之后角度固定为−7°。太空场景里雨伞飞出的路径也改成了另一组关键帧。

- 对象：`rain.umbrella`, `rain.helmet`, `space.umbrella`
- 查看时间：5.20 秒
- 原作：src/dressup.tsx:9、33、37：头盔x/y/angle都含sin；雨伞rotate = −29 + 3sin(6t)，继承角色变换；太空雨伞使用局部y线性上移。
- 复刻：src/Replica.tsx:95–111：雨伞固定角度或关键帧转动；头盔使用ease进场，rotate(−7)。

## 3. 星空：向下移动变成了原地闪烁

原作105个小星点的位置随时间向下移动；复刻125个星点的坐标固定，只改变透明度。三颗大星光都画出来了，但出现间隔、旋转速度、位置变化和轮廓不一致。

- 对象：`space.stars`, `space.sparkles`
- 查看时间：7.00 秒
- 原作：src/dressup.tsx:35、38：105个星点，y = (rand(...) × 720 + 4t) % 720；大星光逐个间隔0.15秒，用sin位移及30t角度。
- 复刻：src/Replica.tsx:124、149–151：125个星点，x/y固定、opacity = .75 + .25sin(...)；大星光间隔6帧，angle = 7 × (f − start)。

## 4. 雪景：树木停住，角色和小恐龙另编了动作

原作松树会轻微横移，复刻的树木完全静止。原作角色和小恐龙用连续的正弦函数摆动；复刻改用若干关键帧和不同频率，导致同一时刻的倾斜、位置和腿部动作不同。

- 对象：`snow.trees`, `snow.suit`, `snow.dinosaur`
- 查看时间：8.20 秒
- 原作：src/dressup.tsx:19、40–41：树x加5sin(t)；角色角度3sin(6(t−7.4))；小恐龙位移、上下与转角各自连续计算。
- 复刻：src/Replica.tsx:154–160、174–190：treeData和Trees没有时间输入；SnowSuit用关键帧角度；Dinosaur另加左右腿交替动作。

## 5. 粒子：数量和大致方向接近，分布与轨迹没有还原

雨滴由150个变为165个，雪花由100个变为95个，随机分布和速度也不同。转场的12个十字粒子原作向外匀速散开、持续缩小；复刻改了初始半径、缩放曲线并加入透明度淡入淡出。

- 对象：`rain.drops`, `snow.flakes`, `transition.rain`, `transition.space`, `transition.snow`, `transition.jungle`
- 查看时间：4.37 秒
- 原作：src/dressup.tsx:14、32、40：转场p=(t−start)/.35，半径310+330p / 225+230p，尺寸13→3，opacity保持1。
- 复刻：src/Replica.tsx:117、156、214–220：雨滴165、雪花95；转场半径、尺寸和透明度分别用关键帧控制。

## 6. 小恐龙：轮廓、比例与关节动作有差异

小恐龙的头、背脊、尾巴和腿由另一组矩形和路径重画，整体比例与原作不同；复刻额外加入独立腿部摆动。丛林大角色的腹部条纹、尾巴和摆动角度也没有逐一还原。

- 对象：`snow.dinosaur`, `jungle.dinosaur`, `jungle.suit`
- 查看时间：9.20 秒
- 原作：src/dressup.tsx:12、43：小恐龙使用一组固定轮廓路径，外层进行整体位移/旋转；大角色角度−5+5sin(10t)。
- 复刻：src/Replica.tsx:171–181、197–210：小恐龙重新组合多个矩形，腿部另含4sin(.52f)；大角色角度使用分段关键帧。

## 评分解释

动效绑定检查确定同一对象、部件和语义属性是否发生变化。运动参数检查进一步比较对应时刻的位置、角度、大小、透明度和形状变化。因此，绑定高分仍可能伴随运动低分。

对象存在检查考察公开要求的真实绘制部件及集合成员。它不表示外观和动作已经正确。额外装饰不当成必需部件缺失；公开集合的成员数量另行核对。

视频对照保留完整画面；自动源码分数不覆盖音频相似度、字体字形像素、模糊与抗锯齿。
