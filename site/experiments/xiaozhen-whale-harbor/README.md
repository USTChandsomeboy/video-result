# 小镇姑娘 · 鲸鱼娘 MV 复刻

[打开视频对比与评分](https://ustchandsomeboy.github.io/video-result/experiments/xiaozhen-whale-harbor/index.html)。

34 秒、1920×1080、30 fps。复刻源码评分 **63.73 / 100**，66 个对象、3,534 项检查全部有结果。同版任务的原作在 Harbor 中实际渲染并独立评分，全部检查为 100 分；225 项回归检查通过。

复刻 agent 获得参考视频、对象卡片、原作音轨和字体，角色与道具由 SVG / HTML 重新绘制。原始提交在渲染时达到时限，随后对同一份源码完成原生分辨率渲染，并交给独立环境评分。

页面支持同步播放、逐帧、关键时间点、六维分数、对象汇总和逐项源码证据。主要差异是逐字歌词弹跳、女孩离开、男孩挥手和星座描边过程。完整字体像素轮廓、纸面滤镜和音频听感通过视频查看。

此前 50.73 分因歌词动态编号及字幕定位误判已撤回；本次对同一提交重评。2,027 项非歌词检查的分数保持一致。详情见 evidence/result-summary.md 和评分器修正记录。
