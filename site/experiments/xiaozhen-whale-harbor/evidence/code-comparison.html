小镇姑娘：原作与复刻的源码差异

本次复刻覆盖 34 秒、11 个场景。子 agent 只获得参考视频、对象卡片、音轨和字体；角色、道具与背景由 SVG / HTML 重新绘制。下列结论来自两份源码，视频截图用于核对可见效果。正式分数由封存后的评分器另行计算。

1. 歌词被简化为换色，漏掉了逐字弹跳

原作在每个字唱到时，计算连续的进度 k，把位移与缩放应用到该字：

transform: `translateY(${-Math.sin(k * Math.PI) * 8}px)
            scale(${1 + Math.sin(k * Math.PI) * 0.12})`

复刻的字节点只按照阈值切换 color，没有对应的位移与缩放。原作整行字幕还包含 5 帧渐入、7 帧上移和 4 帧渐出，复刻主要通过条件分支直接显示和移除。

逐字时间也不同。例如第一句第 2 个字，原作在 0.62 秒开始点亮，复刻在 0.23 秒就切换颜色。因此“歌词内容正确”不能说明“歌词动效正确”。

源码位置：原作 src/MV.tsx 的 Subtitles 与 src/lyrics.ts；复刻 src/Replica.tsx 的 Lyrics。

2. 女孩离开：保留了平移，漏掉转身、缩小和消失

原作 SceneLetGo 的女孩有四个相连的变化：

• 第 18 帧转向并开始走动。

• 从 x=1040 移动到 x=1340。

• 缩放从 1.1 变为 0.8，表现走远。

• 第 40–56 帧透明度从 1 降到 0。

复刻 SceneLetgo 使用 move = 65 * ease(t / 2.02)，女孩主要向右平移 65 个画布像素，缩放固定为 1，也没有原作的离开渐隐。两边的人物坐标定义不同，以上数值描述各自函数，屏幕结果以共同画布上的有效属性为准。

辅助截图：4.60 秒对比。

3. 挥手：有摆动，但姿态、幅度和速度不同

原作把 140 + Math.sin(f / 3) * 22 传给男孩右臂；复刻的挥手角度为 -43 + Math.sin(t * 7) * 13。原作 f 是局部帧数，复刻 t 是局部秒数，两边转轴和角度约定也不同。

因此不能直接比较变量名或角度常数。检查应比较实际右臂经过父级变换后的姿态与轨迹。视频中，原作手臂举起，复刻在相同时间更接近向侧下方伸出。

源码位置：原作 src/scenes30s.tsx / src/characters.tsx；复刻 src/Replica.tsx 的 SceneLetgo / BoxBoy。

4. 星座：形状相近，但绘制过程明显提前

以下为星座场景内的局部时间：

部件原作开始 → 完成复刻开始 → 完成
鲸鱼身体连线0.80 → 2.27 秒0.15 → 1.40 秒
尾部连线1.40 → 2.47 秒1.04 → 1.79 秒
喷水连线1.67 → 2.60 秒1.68 → 2.30 秒

原作通过 strokeDashoffset 按各段时间绘线。复刻也使用描边偏移，但开始和持续时间不同，且使用了不同的缓动。因此最终形状相似，中间帧仍有明显差别。

辅助截图：23.50 秒对比。

源码位置：原作 src/scenes30s.tsx 的 SceneStars / draw；复刻 src/Replica.tsx 的 ConstellationLine。

5. 风筝绳：两端都在移动，但要检查是否连到实际手部

原作通过 boyHand(...) 从男孩的位置、缩放和手臂角度计算绳子的手部端点。复刻使用 handx = bx + 205、handy = by - 23，没有把男孩整体旋转及手臂旋转纳入端点计算。

这会产生“绳子与人物同时运动，但连接关系不准确”的情况。应检查绳端点与实际手部的位置关系，而不仅确认绳子存在或 x/y 随时间变化。

辅助截图：10.50 秒对比。

评分范围

源码评分覆盖公开登记的对象及部件、几何与颜色、相对关系、有效动效绑定、运动参数和进出时序。字体实际像素排版、纸面滤镜、遮挡与音频听感不计入这份源码分数。上述源码分析中的跨对象连接关系，也需要以实际检查清单为准；不会把人工观察直接加成扣分项。
