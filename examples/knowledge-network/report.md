# 知识讲解｜网络拓扑

## 对比内容

左侧是参考视频，右侧是 Remotion 复刻视频。下面记录本例中可以直接观察到的差异。

## 观察到的差异

1. **对象存在与强调（约 1.5 秒）**：参考服务器卡片先整体存在，再用手指强调；复刻把它们全部做成淡入。 原因：没有区分已有对象和当前被强调对象。
2. **标签绑定（约 4.5 秒）**：参考 IP、域名和服务器图标一起出现；复刻标签独立于图标按网格出现。 原因：文字没有绑定到对象的进入状态和位置。
3. **对话因果（约 8 秒）**：参考气泡按服务器之间的问答关系依次出现；复刻把气泡当作同步字幕。 原因：对象之间的指示关系被压平成文字层。
4. **清场后重建（约 11.5 秒）**：参考先清空卡片，再建立主干和节点；复刻直接把拓扑叠在旧场景上。 原因：场景状态切换的清空边界不明确。
5. **拓扑生长（约 14.2 秒）**：参考主干、竖线、节点、标签逐层完成；复刻一次性画出全部连线。 原因：连线终点没有绑定节点，拓扑顺序丢失。

这些差异用于定位复刻结果中的具体问题。
